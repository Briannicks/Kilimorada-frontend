## Brand & Style

The design system establishes a high-utility, calm, and dependable interface tailored for administrative officers, agricultural data analysts, and regional field coordinators in Kenya. The visual philosophy balances rigorous enterprise efficiency with approachable clarity, avoiding technical clutter and decorative indulgence.

The aesthetic blends crisp Modern Enterprise structure with disciplined Minimalism:
- Flat, non-distracting surfaces optimized for sustained daily operational use under varied indoor and field ambient lighting conditions.
- Strict restraint: absolute rejection of synthetic visual trends (no gradients, glassmorphism, glowing auras, or whimsical decorative elements).
- Dignified, purposeful presence using precision spacing, razor-sharp single-pixel delineations, and high typographic contrast.

## Colors

The palette is rooted in agrarian vitality grounded by structural slate neutrals, conveying trustworthiness, operational discipline, and environmental focus.

### Core Swatches
- **Primary Green (`#15803D`)**: The primary anchor used exclusively for primary calls-to-action, active status indicators, key interactive controls, and authoritative data accents.
- **Primary Hover (`#166534`)**: Pressed and hover states for primary interactive components.
- **Light Green Tint (`#F0FDF4`)**: Semantic surface tint used strictly for active navigation pill fills, selected rows, and positive status badge containers.
- **Green Accent / Border (`#BBF7D0`)**: Subtle contextual borders on green containers, badge perimeters, and active perimeter cues.
- **Canvas / Page Background (`#F7F9F8`)**: Soft, muted greenish-grey providing comfortable contrast against pure white cards without glare.
- **Surface / Card Background (`#FFFFFF`)**: Pure flat white for all data tables, analytics panels, and dashboard cards.
- **Surface Borders (`#E2E8F0`)**: Crisp 1px structural framing for cards, table dividers, headers, and form fields.

### Typographic Tiers
- **Heading Text (`#0F172A`)**: Deep slate for maximum legibility on headers, metric figures, and primary table keys.
- **Body Text (`#475569`)**: Balanced medium slate for descriptive labels, secondary metrics, and paragraph text.
- **Muted Text (`#94A3B8`)**: Low-emphasis hints, table column captions, breadcrumbs, and disabled states.

### Status Palette
- **Danger (`#DC2626`)**: Critical alerts, yield failure warnings, system errors, and destructive actions.
- **Warning (`#D97706`)**: Pending inspections, delayed synchronizations, and threshold warnings.
- **Success (`#15803D`)**: Satisfactory harvest reports, verified geo-tagging, and system connectivity confirmations.

## Typography

Typographic hierarchy relies exclusively on `Inter` across all structural tiers to maintain systematic clarity and performance across web and low-bandwidth remote operations.

- **Weight Economy**: Rely on 400 (Regular) for body prose and descriptive data, 500 (Medium) for functional controls and tabular headers, 600 (Semi-bold) for card titles and section anchors, and 700 (Bold) for critical KPI counters and primary page headers.
- **Tabular Figures**: For tables, geographic coordinates, currency (`KES`), metric yields (`kg/ha`), and numeric lists, activate `font-feature-settings: "tnum" 1` to ensure aligned vertical scanning.
- **Letter Spacing**: Tighten large metrics and primary headings slightly (`-0.01em` to `-0.02em`) to preserve structural cohesion; open micro labels (`label-sm`) with `0.04em` for crisp readability in status tags and badge counters.

## Layout & Spacing

The layout is built around a structured, fluid enterprise grid that supports high information density without visual crowding.

### Grid & Breakpoints
- **Desktop (1024px and above)**: 12-column fluid grid, `2rem` outer canvas margin, `1.5rem` gutters. Permanent or collapsible 260px administrative navigation sidebar.
- **Tablet (768px – 1023px)**: 8-column fluid grid, `1.5rem` outer margins, `1rem` gutters. Sidebar collapses to a fixed rail or modal drawer.
- **Mobile (below 768px)**: 4-column single-stream reflow, `1rem` outer margins, `1rem` gutters. Top utility bar with bottom sheet or slide-in menu for field operations.

### Rhythmic Discipline
- Component padding strictly consumes the `space-*` scale.
- Metric cards: `space-lg` (24px) internal padding.
- Compact list items and table cells: `space-sm` vertical (8px) and `space-md` horizontal (16px).
- Generous empty space separates logical regions, maintaining clear scanning paths across analytical tables and telemetry feeds.

## Elevation & Depth

The design system achieves hierarchy entirely through structural borders and flat tonal stacking, avoiding atmospheric effects.

- **Flat Surface Separation**: Depth is created primarily by sitting pure white surfaces (`#FFFFFF`) on top of the soft greenish-grey canvas (`#F7F9F8`), bounded by crisp 1px borders (`#E2E8F0`).
- **No Gradients, No Glassmorphism**: Translucency, frosted backdrops, and multi-color gradient fills are strictly prohibited. Every layer is 100% opaque.
- **Soft Neutral Shadows**: When elevation is required for floating navigation, action menus, or dropdown popovers, employ only a clean, tight, neutral shadow:
  - Base Card / Surface: Flat with 1px solid `#E2E8F0` border.
  - Floating Elements (Dropdowns, Dialogs, Modals): `box-shadow: 0 1px 2px 0 rgba(15, 23, 42, 0.05)`.
  - Overlays & Popovers: `box-shadow: 0 4px 6px -1px rgba(15, 23, 42, 0.07), 0 2px 4px -2px rgba(15, 23, 42, 0.05)` coupled with a 1px solid `#E2E8F0` border.

## Shapes

The interface pairs structured, functional card envelopes with approachable, fully pill-shaped interactive targets.

- **Cards & Data Panels (`rounded-xl` / 1.5rem - 24px)**: Generous corner radii soften the enterprise structure while maintaining clean enclosure for charts and tables.
- **Interactive Controls (`rounded-full` / 9999px)**: Buttons, text inputs, search fields, select triggers, and status chips use full pill geometry. This distinct silhouette ensures interactive elements instantly differentiate from static content blocks.
- **Small Indicators & Tooltips (`rounded` / 0.5rem - 8px)**: Minor metadata blocks, dropdown menus, and operational badges use compact, balanced rounding.
